# Обновление 0.4.0 — прямое выполнение проверки помощником

## Новый принцип

Приложение собирает данные объекта и инструкции и формирует полное самостоятельное задание. Помощник выполняет проверку, работу в AutoCAD и контроль качества сам через AUTOM8LABS. Промежуточное подтверждение в приложении и отдельный встроенный построитель для новых запусков не используются.

## Интерфейс

- сохранены без изменения поля паспорта объекта;
- сохранены формы исходных данных оценки преград;
- вкладка «Проверка» заменена вкладкой «Задание»;
- одна кнопка создаёт и сразу копирует полное задание;
- удалены вкладки «Контроль» и «Как работать»;
- из оценки преград удалена вкладка «Построение и проверка»;
- удалена кнопка ручной проверки реестра.

## Состав задания

Каждый новый запуск сохраняет полный паспорт, готовность, последовательность, список файлов правил с SHA256, полный текст правил, общий и специальный контроль качества, пути запуска и условия завершения. Создаются файлы `ЗАДАНИЕ_ДЛЯ_ЧАТА.md`, `ПРАВИЛА_ЗАПУСКА.md`, `КОНТРОЛЬ_КАЧЕСТВА.md`, `run.json` и `РЕЕСТР_ПРОВЕРКИ.json`.

## AutoCAD и контроль

До первой изменяющей операции помощник создаёт отдельную копию результата рядом с исходным DWG и выполняет работу в ней. После нанесения он проверяет AutoCAD-id, геометрию, слои, цвета, веса, стили, цели лучей, полноту, наложения и специальные требования режима. Итоговый чек-лист записывается через `record_quality_control`; результат регистрируется через `record_result_dwg`.

## Инструкции режимов

Готовность режима определяется содержимым его редактируемой инструкции. Пока в файле находится отметка «алгоритм этого вида проверки ещё не передан пользователем», изменения AutoCAD запрещены. После замены этой отметки полноценной инструкцией новый запуск активируется без изменения кода.

Старые контрольные модули сохранены только для совместимости с историей и не показываются в новом интерфейсе и списке инструментов новых заданий.
