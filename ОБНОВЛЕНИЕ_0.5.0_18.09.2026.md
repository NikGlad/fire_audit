# Обновление 0.5.0 от 18.09.2026

Для каждого вида проверки во вкладке **Задание** добавлен выбор результата:

1. **Полная проверка с AutoCAD** — анализ, формирование замечаний, работа через AUTOM8LABS и итоговая проверенная копия DWG.
2. **Анализ и задание в Word** — полный сбор сведений и нормативный анализ без изменения AutoCAD; итогом служит понятный человеку файл `ЗАДАНИЕ_ПО_РЕЗУЛЬТАТАМ_АНАЛИЗА.docx`.

В аналитическом Word-задании обязательно указываются точные места, существующее состояние, требуемые действия, готовые тексты замечаний и запросов, нормы, редакции, пункты, область применения, исключения и обоснования. Для графики указываются ориентиры и требуемое оформление. Для оценки преград отдельно охватываются границы, заполнения проёмов, категории, венткамеры, шахты, коридорные деления, выноски и легенда.

Добавлены отдельный контроль качества Word-документа, обязательный постраничный рендер и визуальная проверка, регистрация результата через `record_word_report` и строгая проверка завершённости. История запусков показывает выбранный результат. Старые запуски без нового поля продолжают открываться как полная проверка с AutoCAD.

Состав сбора информации об объекте не изменён.
