# Нормы для объекта

Эта инструкция действует **только** для результата работы `Нормы для объекта` (`task_variant=object_norms`). Она дополняет обязательный пользовательский регламент поиска по документам пожарной безопасности, особенно его раздел 10. Для обычной оценки соответствия АР она не меняет порядок выдачи замечаний. В данном варианте задания любые указания других инструкций о построении замечаний, лучей, обмеров и сохранении DWG не применяются: работа только аналитическая.

## Предмет результата

Собрать исчерпывающий в пределах подтверждённых исходных данных перечень **применимых к выбранному объекту** требований сводов правил в области пожарной безопасности. Это отдельное исследование, а не проверка наличия нарушений, не построение замечаний и не изменение AutoCAD. Использовать только паспорт выбранного объекта, его дополнительные данные, переданные заказчиком планы и документы. Не переносить параметры других объектов.

Федеральное агентство по техническому регулированию и метрологии (Росстандарт): до чтения требований выбрать относящуюся к дате ГПЗУ редакцию перечня по приказу № 2594 из репозитория пользователя и проверить **точное включение** каждого СП, пункта, подпункта, части пункта, таблицы, примечания или приложения. Не считать включённым весь СП лишь по упоминанию его номера. Не включённые в перечень фрагменты не добавлять в основной перечень без отдельного указания пользователя; отметить отдельно, если они существенны для понимания.

## Алгоритм отбора

1. Зафиксировать дату ГПЗУ, назначение всего здания и функциональных частей, встроенность/пристроенность, этажность, высоту, площади, численность людей, степень огнестойкости, класс конструктивной пожарной опасности, категории, пожарные отсеки, МГН и иные условия применимости. Проверить исходные сведения по паспорту и материалам заказчика. Неизвестное не превращать в факт.
2. По регламенту сначала исследовать папку `рабочая`, затем связанные документы, письма ВНИИПО и, где требуется, официальные источники. Проверить `normative_status`; поисковый индекс использовать только для навигации. Для каждого относящегося требования прочитать первичный текст полностью, включая область применения СП, вводные положения раздела, примечания, таблицы, сноски, приложения, исключения и перекрёстные ссылки. Сканы и сомнительные цифры проверить по изображению страницы.
3. Составить карту тем из раздела 10 регламента: классификация; объёмно-планировочные решения; пожарные отсеки и преграды; огнестойкость; эвакуация; противодымная защита и вентиляция; АПС, СОУЭ, АУП; водоснабжение; доступ пожарных подразделений; специальные требования по назначению; эксплуатация, если на неё распространяются рассматриваемые СП. Не ограничивать поиск только пунктами, уже упомянутыми в замечаниях или блоках AutoCAD.
4. По каждой теме составить перечень потенциально относящихся СП и их редакций. Для **каждого** пункта сверить одновременно: включение конкретного фрагмента в перечень Росстандарта, действие редакции на дату ГПЗУ, область действия СП/раздела/подраздела/пункта, фактические параметры объекта, все условия и исключения. Если в пункте применима только часть, выделить именно эту часть и пояснить границу отбора. Не копировать весь пункт автоматически.
5. В основной перечень включать только подтверждённо применимые требования. Пункты, зависящие от неизвестной категории, количества людей, системы защиты, назначения помещения или иной неустановленной вводной, выносить в отдельный раздел «Требуется уточнение»: условие, недостающий факт, точный вопрос заказчику. Заведомо неприменимые требования вынести в краткий контрольный реестр исключений с причиной, чтобы показать полноту охвата без загрязнения основного перечня.
6. Убирать дубли, проверять конфликт общих и специальных норм, дату изменения редакции, статус письма ВНИИПО. Письмо — разъяснение, а не самостоятельная обязательная норма. Не выдавать проектную рекомендацию за требование СП.

## Итоговый документ

Сформировать Word-файл `НОРМЫ_ДЛЯ_ОБЪЕКТА.docx` в папке запуска. Группировать по темам. Каждая строка матрицы должна содержать: точный СП и редакцию; пункт/подпункт/часть/таблицу/примечание; краткий нормативный фрагмент без смешения с комментариями; условие применимости; подтверждённый факт выбранного объекта и его источник; проверку включения в перечень № 2594 (редакция и точный фрагмент); применимую часть требования; необходимое действие/проверяемый параметр; исключения; источник нормативного текста, страницу, SHA256 или иной идентификатор версии; статус визуальной проверки скана, если она нужна.

Отдельно перечислить: принятые исходные данные; карту проверенных тем и документов; вопросы по недостающим сведениям; исключённые кандидаты с причинами; ограничения полноты при недоступных, непрочитанных или противоречащих источниках. Если полноту невозможно подтвердить, не писать «все требования собраны» без оговорки. Доказательные выводы основывать на прочитанных документах, а не на поисковой выдаче.

AutoCAD при необходимости использовать через `AUTOM8LABS MCP Connector for AutoCAD` **только для чтения** фактов объекта. Не создавать графику, не менять и не сохранять DWG. Итоговый DOCX отрендерить и визуально проверить каждую страницу.
